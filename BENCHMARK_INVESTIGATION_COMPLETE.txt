CONTEXT

- Native SSD speeds: 1-3 GB/s

- This is the performance bottleneck mentioned in CLAUDE.md architecture

KEY INSIGHT
The Plan 9 protocol used by /mnt/c (virtiofs or drvfs) creates significant
I/O overhead. Strix-Turbo parasitic_batch tool aims to optimize syscall
batching to reduce VM exits and improve this performance.

- Not extremely slow (would expect 50-100 MB/s worst case)

CACHE DROP OPERATION
The "echo 3 | sudo tee /proc/sys/vm/drop_caches" operation:
- Flushes filesystem cache
- Necessary for fair I/O benchmarking
- Can be slow on WSL2 with virtiofs
- Now has timeout protection
