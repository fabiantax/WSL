### If new kernel doesn't load
1. Check .wslconfig path: `notepad C:\Users\fabia\.wslconfig`
2. Verify kernel exists: `dir C:\Users\fabia\bzImage-zen5-hwe`
3. Check for typos in kernel path (must use double backslashes: `\\`)
4. Ensure wsl.exe can access the file
